Mit dem Lager in der Mobile-App finden Sie Werkzeug und Material per Barcode und buchen Entnahmen dort, wo sie passieren. Jede Buchung bestätigen Sie vor dem Speichern.

## Voraussetzungen

- Sie nutzen die Mobile-App, auch mit App-Lizenz.
- Ihr Betrieb hat Ihnen die passenden Lager freigegeben.
- Werkzeug und Material tragen einen Barcode oder einen Inventarcode.

## Schritt für Schritt in der Mobile-App

### Scannen und buchen

1. Tippen Sie „Mehr“ und dann „Lager“.
2. Tippen Sie „Barcode scannen“ und halten Sie nur einen Code ins Bild.
3. Prüfen Sie den Code und tippen Sie „Code prüfen und suchen“.
4. Prüfen Sie beim Treffer den „Bestand nach Lagerort“.
5. Tippen Sie „Ausgabe, Rücknahme oder Bewegung“.
6. Wählen Sie unter „Bewegung prüfen“ die „Aktion“, das „Projekt“ oder das „Ziellager“ und die Menge.
7. Tippen Sie „Buchung bestätigen“.

Neue Ware buchen Sie beim Artikel mit „Zubuchen“ ein.

### Neuen Lagerbestand erfassen

1. Tippen Sie in „Lager“ auf „Neu erfassen“.
2. Fotografieren Sie Werkzeug oder Etikett und tippen Sie bei Bedarf „Foto mit KI erkennen“.
3. Prüfen Sie unter „Eintrag prüfen“ die „Bezeichnung“, die „Bestandsart“ und das „Lager“.
4. Wählen Sie „Anfangsbestand bewusst einbuchen“ oder „Zunächst ohne Bestand anlegen“.
5. Tippen Sie „Geprüften Eintrag anlegen“.

Die KI-Erkennung holen Sie auf Anforderung; sie braucht eine Internetverbindung und verbraucht Betriebscredits. Die App nennt den Verbrauch vor dem Start. Je Foto fallen bis zu 2 Credits an, ab dem 1. Januar 2027 bis zu 3 Credits.

## Ergebnis prüfen

Mit Verbindung meldet die App „Buchung synchronisiert.“, und der Vorgang erscheint unter „Letzte Vorgänge“. Ohne Netz steht die Buchung als „Auf Gerät vorgemerkt“ in der Liste; der Server prüft den verfügbaren Bestand, sobald wieder eine Verbindung besteht.

## Häufige Probleme

### Was speichert ein Scan?

Eine Sichtung mit Zeitpunkt. Ausgabe, Rücknahme und Mengenbuchungen bestätigen Sie anschließend separat mit „Buchung bestätigen“.

### Was tun, wenn die Kamera den Code nicht erkennt?

Tippen Sie „Barcode fotografieren“ oder geben Sie den Code unter „Barcode oder Inventarcode“ von Hand ein. Halten Sie den Code ruhig und gut beleuchtet in den Rahmen.

### Was bedeutet „Prüfung erforderlich“?

Ein vorgemerkter Vorgang wurde abgewiesen oder der Bestand hat sich geändert. Tippen Sie „Aktuellen Stand laden“ und prüfen Sie Menge, Lager und Projekt vor einer neuen Buchung.

### Was tun mit einem Code, der noch keinem Eintrag gehört?

Die App zeigt „Code noch nicht zugeordnet“. Tippen Sie „Neuen Eintrag erfassen“ oder ordnen Sie den Code einem bestehenden Eintrag zu.
