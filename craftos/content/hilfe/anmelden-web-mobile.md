Sie benötigen ein bestehendes CraftOS-Konto, Zugriff auf dessen E-Mail-Adresse und eine Internetverbindung; die Web-App setzt eine Admin- oder Büro-Lizenz voraus.

## In der Web-App anmelden

1. Öffnen Sie die CraftOS-Anmeldeseite und wählen Sie „Anmelden“.
2. Geben Sie die E-Mail-Adresse Ihres Kontos und das Passwort ein.
3. Wählen Sie „Anmelden“ und warten Sie auf die Weiterleitung.
4. Ohne Passwort wählen Sie „Kein Passwort? Mit Code anmelden“.
5. Geben Sie Ihre E-Mail-Adresse ein und wählen Sie „Code senden“.
6. Tragen Sie den sechsstelligen Code aus der E-Mail ein und bestätigen Sie die Anmeldung.

Verwenden Sie bei einem mit Google registrierten Konto dieselbe Google-E-Mail-Adresse für den E-Mail-Code.

## In der Mobile-App anmelden

1. Öffnen Sie die App und wählen Sie „Code“ oder „Passwort“.
2. Geben Sie Ihre Konto-E-Mail-Adresse ein.
3. Fordern Sie bei „Code“ über „Code senden“ den Anmeldecode an.
4. Tragen Sie den aktuellen Code ein; bei „Passwort“ verwenden Sie das hinterlegte Passwort.
5. Prüfen Sie nach der Anmeldung, ob die erwarteten Projekte beziehungsweise Einsätze sichtbar sind.

Eine reine App-Lizenz ist für diesen mobilen Zugang vorgesehen. Sie schaltet nicht automatisch die Web-Verwaltung frei.

## Ergebnis und Fehlerhilfe

Nach erfolgreicher Anmeldung sehen Sie die für Ihre Rolle freigegebenen Bereiche. Fehlen Projekte, lassen Sie die Projektzuordnung prüfen.

Bei ausbleibender E-Mail kontrollieren Sie Adresse und Spamordner. Warten Sie eine angezeigte Versandpause ab und nutzen Sie anschließend „Code erneut senden“. Bei abgelaufenem Code verwenden Sie ausschließlich den neu angeforderten Code.

Bei einer noch nicht bestätigten E-Mail-Adresse öffnen Sie zuerst die Bestätigungsnachricht. Eine Zugriffssperre wegen Konto oder Abonnement muss die Administration klären; wiederholte Passwortwechsel lösen sie nicht.
