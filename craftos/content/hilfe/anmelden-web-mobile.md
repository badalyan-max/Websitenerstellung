## Voraussetzungen

- Ein CraftOS-Konto und Zugriff auf dessen E-Mail-Postfach.
- Für die Web-App eine Voll-Lizenz (Admin oder Büro), für die Mobile-App eine Voll-Lizenz oder eine App-Lizenz.
- Eine Internetverbindung für die Anmeldung.

Neue Teammitglieder erhalten zuerst eine Einladung per E-Mail und legen darüber ihr Passwort fest ([Mitarbeiter einladen](/hilfe/mitarbeiter-einladen-lizenz-zuweisen)).

## Schritt für Schritt in der Web-App

1. Öffnen Sie die CraftOS-Anmeldeseite.
2. Tragen Sie unter „E-Mail“ Ihre Konto-E-Mail-Adresse ein.
3. Tragen Sie unter „Passwort“ Ihr Passwort ein.
4. Klicken Sie auf „Anmelden“.

Ohne Passwort melden Sie sich mit einem Code an:

1. Klicken Sie auf „Kein Passwort? Mit Code anmelden“.
2. Tragen Sie unter „E-Mail“ Ihre Konto-E-Mail-Adresse ein.
3. Klicken Sie auf „Code senden“.
4. Tragen Sie den sechsstelligen Code aus der E-Mail unter „Anmeldecode“ ein.

Haben Sie Ihr Konto mit Google angelegt, nutzen Sie „Mit Google anmelden“ oder fordern den Code an Ihre Google-E-Mail-Adresse an.

## Schritt für Schritt in der Mobile-App

1. Öffnen Sie die CraftOS-App.
2. Tippen Sie auf „Code“.
3. Tragen Sie unter „E-Mail“ Ihre Konto-E-Mail-Adresse ein.
4. Tippen Sie auf „Code senden“.
5. Tragen Sie den sechsstelligen Code unter „Code aus der E-Mail“ ein.

Mit Passwort tippen Sie auf „Passwort“, tragen E-Mail-Adresse und Passwort ein und tippen auf „Anmelden“. Die App gilt je Konto für ein Mobilgerät („Ein Konto, ein Mobilgerät“): Eine neue Anmeldung auf einem anderen Gerät meldet das bisherige Gerät ab.

## Ergebnis prüfen

Nach der Anmeldung sehen Sie die Bereiche, die Ihre Rolle freigibt. In der Mobile-App erscheinen die Projekte, in deren Projektteam Sie stehen, und Ihre Einsätze. Fehlt ein Projekt, trägt das Büro Sie im Projekt unter „Projektteam“ ein.

## Häufige Probleme

### Was tun, wenn keine Code-E-Mail ankommt?

Prüfen Sie die Schreibweise der Adresse und den Spam-Ordner. Nach der angezeigten Wartezeit fordern Sie mit „Code erneut senden“ einen neuen Code an und verwenden nur diesen neuen Code.

### Was bedeutet „E-Mail-Adresse noch nicht bestätigt“?

Öffnen Sie zuerst den Link aus der Bestätigungs-E-Mail, die CraftOS nach der Registrierung gesendet hat. Danach melden Sie sich mit Passwort oder Code an.

### Was zeigt die Web-App bei einer App-Lizenz?

Mit einer App-Lizenz zeigt die Web-App den Hinweis „Nur in der App verfügbar“. Melden Sie sich in der Mobile-App an. Braucht die Person Büro-Zugang, weist ihr der Inhaber unter „Rollen & Rechte“ eine Voll-Lizenz zu.

### Warum wurde ich in der Mobile-App abgemeldet?

Ihr Konto hat sich auf einem anderen Mobilgerät angemeldet. Melden Sie sich erneut an; jede Person nutzt einen eigenen Zugang. Mehr dazu erklärt die Funktion [Team und Zugriff](/funktionen/team).
